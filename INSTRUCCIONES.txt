====================================================
  BBVA FAKE - Instrucciones de instalacion y uso
====================================================

PRERREQUISITOS
--------------
1. Node.js >= 18
2. SQL Server 2019+ o SQL Server Express
3. SQL Server Management Studio (SSMS), Azure Data Studio o herramienta similar

PASO 1 - Base de datos
----------------------
1. Abre SQL Server.
2. Ejecuta el script:
   database/BD_BBVA.sql

Esto crea BD_BBVA con tablas de usuarios, cuentas y transferencias.

PASO 2 - Configurar backend/.env
--------------------------------
1. Copia backend/.env.example como backend/.env.
2. Ajusta la conexion. Para usar tu sesion de Windows en SQL Server:

   PORT=3000
   DB_SERVER=LAPTOPVALE
   DB_DATABASE=BD_BBVA
   DB_AUTH_TYPE=windows
   DB_ODBC_DRIVER=ODBC Driver 18 for SQL Server
   DB_ENCRYPT=false
   DB_TRUST_CERT=true
   JWT_SECRET=bbva_fake_jwt_secret_2024_muy_seguro
   JWT_EXPIRES_IN=8h

   Si tu SQL Server es una instancia nombrada, usa algo como:
   DB_SERVER=LAPTOPVALE\SQLEXPRESS

   Si prefieres usuario y contrasena de SQL Server, cambia a:
   DB_AUTH_TYPE=sql
   DB_PORT=1433
   DB_USER=sa
   DB_PASSWORD=TuPasswordSQL123!

PASO 3 - Instalar dependencias y cargar datos
---------------------------------------------
  cd backend
  npm install
  npm run seed

Usuarios de prueba:
  admin@bbva.com   / Admin1!   (administrador)
  carlos@bbva.com  / Carlos1!  (cliente)
  maria@bbva.com   / Maria1!   (cliente)
  juan@bbva.com    / Juan1!    (cliente con saldo insuficiente)
  luisa@bbva.com   / Luisa1!   (cliente cerca del limite)
  pedro@bbva.com   / Pedro1!   (bloqueado)
  ana@bbva.com     / Ana1!     (cliente)

PASO 4 - Iniciar servidor
-------------------------
  npm start

Abre en el navegador:
  http://localhost:3000

IMPORTANTE
----------
El frontend ya no usa localStorage como base de datos bancaria.
Ahora llama al backend con fetch y JWT:

  POST  /api/auth/login
  POST  /api/auth/register
  GET   /api/cuentas/resumen
  GET   /api/cuentas/mi-cuenta
  GET   /api/cuentas/movimientos?page=1
  POST  /api/transferencias
  GET   /api/admin/cuentas
  GET   /api/admin/transferencias
  POST  /api/admin/usuarios
  PATCH /api/admin/usuarios/:id/desbloquear

El navegador solo guarda el token y el usuario de sesion en sessionStorage.
Los usuarios, cuentas, saldos, bloqueos y transferencias se guardan en SQL Server.

PRUEBAS UNITARIAS
-----------------
  cd backend
  npm test

REGLAS DE NEGOCIO
-----------------
- Monto minimo por transferencia: $500.00
- Limite diario de envio: $7,000.00
- Saldo maximo por cuenta: $50,000.00
- Bloqueo tras superar 3 intentos fallidos
- Solo el administrador puede reactivar cuentas bloqueadas
- Contrasena: 5-8 caracteres, mayuscula, numero y caracter especial
- Transferencias permanentes, sin cancelacion
- Historial de 5 movimientos por pagina, sin filtros
